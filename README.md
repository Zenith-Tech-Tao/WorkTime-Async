# WorkTime Async — Бот учёта рабочих часов

Telegram-бот для учёта отработанных часов и автоматического подсчёта зарплаты.

---

## О проекте

Это переработанная и улучшенная версия предыдущего проекта, написанного на **telebot** (синхронная библиотека).

Основная проблема старого проекта — синхронность. При большом количестве пользователей бот начинал тормозить: пока обрабатывался один запрос, остальные стояли в очереди. Новая версия написана на **aiogram 3** с полной асинхронностью, что решает эту проблему.

Помимо смены библиотеки, проект был полностью переосмыслен с точки зрения структуры и архитектуры.

---

## Отличия от предыдущей версии

### Архитектура
Старый проект — один большой файл, где всё свалено в кучу. Сейчас код разнесён по директориям и файлам по зонам ответственности: база данных отдельно, роутеры отдельно, клавиатуры отдельно. Читаемость и поддержка кода выросли кратно.

```
WorkTime/
├── main/
│   ├── main.py        — точка входа
│   └── config.py      — токен и ID администратора
├── database/
│   ├── main_DB.py     — инициализация базы данных
│   └── script_DB.py   — все async функции для работы с БД
└── routes/
    ├── command.py          — команда /start
    ├── work.py             — начало и конец смены
    ├── handlers_STATS.py   — статистика
    ├── handlers_ADMIN.py   — команды администратора
    └── keyboards.py        — все клавиатуры
```

### Новые админские команды
В старой версии администратор мог только смотреть данные и удалять их. Сейчас добавлены:

- **`/add_hours`** — добавить часы пользователю вручную. Нужно когда у сотрудника разрядилось устройство и он не смог отметить начало или конец смены — он сообщает время администратору, тот вносит данные через бота.
- **`/rem_hours`** — убрать часы у пользователя. Если выяснилось, что сотрудник нажал «Начать» и забыл закончить, или намеренно накрутил себе часы — администратор может скорректировать данные.

### Полный список команд администратора
| Команда | Описание |
|---|---|
| `/db` | Очистить всю базу данных |
| `/du` | Удалить конкретного пользователя |
| `/add_hours` | Добавить часы пользователю |
| `/rem_hours` | Убрать часы у пользователя |

## Настройка перед запуском

> ⚠️ Файл `config.py` не выложен в репозиторий намеренно — он содержит приватные данные. Тебе нужно создать его самому.

### 1. Получи токен бота
Напиши [@BotFather](https://t.me/BotFather) в Telegram, создай бота командой `/newbot` и скопируй выданный токен.

### 2. Узнай свой Telegram ID
Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой числовой ID.

### 3. Создай файл config.py
В PyCharm: правой кнопкой на папку `main/` → **New** → **Python File** → назови `config`.

Содержимое файла:

```python
TOKEN = "сюда_вставь_токен_от_BotFather"

Admin_id = 123456789  # сюда вставь свой Telegram ID
```

### 4. Установи зависимости

```bash
pip install aiogram aiosqlite
```

### 5. Измени ставку зарплаты (если нужно)

По умолчанию ставка — **400 руб/час**. Она прописана в двух местах:

**`database/script_DB.py`** — функции `db_add_hours` и `db_remove_hours`:
```python
many = round(hours * 400, 2)  # ← меняй 400 на свою ставку
```

**`routes/work.py`** — функция `cb_end_work`:
```python
many = round(hours * 400, 2)  # ← меняй 400 на свою ставку
```

Также ставка отображается в сообщениях статистики — она там указана текстом. Найди в **`routes/handlers_STATS.py`** строки:
```python
f"💵 Ставка: 400 руб./час"  # ← меняй цифру на свою
```

### 6. Запусти бота

```bash
python main/main.py
```

Основная логика, архитектура и алгоритмы — авторские. По большей части это миграция собственного старого проекта на новую библиотеку с полным переосмыслением структуры. Я понимаю каждую строчку кода в этом проекте — что она делает и зачем.
